# AtlasTracker for iPhone

Find an older dose record by date, see related entries together, and share a PDF or CSV while keeping your notes private. The planned App Store edition is US$9.99 once.

## Try the existing free beta

[Join the iPhone beta on Apple TestFlight](https://testflight.apple.com/join/aqwYxxbt). The current full beta is about 3.35 GB. Its [24-second walkthrough](https://krisco65.github.io/atlas-tracker/assets/history-demo.mp4) shows the existing record editor.

1. Create a made-up entry and add a short note.
2. Open **Dashboard → View all dose records**.
3. Edit the note, save, and reopen the entry to see the correction.

Use TestFlight to send feedback about the workflow. Please use fictional examples. AtlasTracker is for personal recordkeeping. Discuss treatment decisions with a qualified clinician.
