# AtlasTracker for iPhone

Keep a dated record on your iPhone. Find an older entry, filter by compound, and correct a saved note without losing the related entries in its group.

**[Join the free iPhone beta on Apple TestFlight](https://testflight.apple.com/join/aqwYxxbt)**

[Watch the 24-second history demo](https://krisco65.github.io/atlas-tracker/). It uses fictional records from the app.

## Try the history

1. Create a made-up entry and add a short note.
2. Open **Dashboard → View all dose records**.
3. Edit the note, save, and reopen the entry to see the correction.

Use TestFlight to send feedback about the workflow. Please use fictional examples in feedback. AtlasTracker is for personal recordkeeping. Discuss treatment decisions with a qualified clinician.
